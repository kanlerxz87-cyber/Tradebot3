Executive summary

Full summary

This dashboard tracks only the five requested topics and ranks live events by official Kalshi contract volume, with a clearly-labelled dollar estimate. Every market row links to its official Kalshi page and its raw API record. Two chat feeds watch for sudden moves: one shows every ≥ $0.10 swing, the other only swings that also pass a transparent liquidity/spread/price-band/runway model.

Contracts are followed until Kalshi settles them; the resolution table records official YES / NO outcomes and settlement values. Automated paper strategies test fade, momentum and model-filtered entries on real candle data, and every trade is categorised so the portfolio page can show which trade types actually worked.

What is live vs. snapshot. The page polls Kalshi's public API every 20 seconds while the tab is visible. If the browser is blocked by CORS or offline, the header says so and the last committed snapshot (timestamped in the status bar above) is used. No price is ever simulated.
