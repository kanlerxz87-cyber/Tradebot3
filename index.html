Verified Kalshi Demo API Specifications

  • Recommended Demo REST: https://external-api.demo.kalshi.co/trade-api/v2 (demo-api.kalshi.co also supported).
  • Recommended Demo WebSocket: wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 (demo-api.kalshi.co also supported).
  • Orderbook Reciprocal Pricing: orderbook_fp returns bids only (yes_dollars, no_dollars); YES Ask = $1.00 − NO Bid.
  • REST / Chart Limit: Kalshi REST candlesticks support 1m, 60m, and 1440m intervals. This static app does not connect an authenticated WebSocket; its chart only shows REST observations collected during this page session (IRREG-04).

Trading, Lifecycle & Verification Discipline

  • Strict 5-Topic Scope: Gas Prices, Elections, Culture, Crypto, and Golf only — isolated into dedicated subpages.
  • Lifecycle: Displays dated production catalog status or a best-effort Kalshi Demo REST status; the two environments may differ. Paper settlement tests do not change market lifecycle.
  • Paper Strategies: Mean-Reversion, Momentum, spread tests, and custom rules record local simulated trades only; the ROI rule is disabled without a sourced fair value. See Portfolio & Strategies.
  • Factual Audit: Unverified prices, changes, and depth stay blank; discrepancies are published on Flagged for Review.
