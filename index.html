Kalshi Demo Dashboard & Executive Summary

Organizes a static Kalshi market reference catalog across five isolated topics — Gas Prices, Elections, Culture, Crypto, and Golf. The dashboard has a local paper simulation for >= $0.10 synthetic swings, interactive simulated charts and orderbook depth, and simulated strategies. It does not display a live market-data stream or place exchange orders.

Static catalog + paper simulation — not a live market feed. Prices/volumes below are reference values, chart histories and depth are synthetic, alerts are generated locally, and trades do not reach Kalshi. Connect a live data relay/API integration before relying on live events.

Verified Kalshi Demo API Specifications

  • Recommended Demo REST: https://external-api.demo.kalshi.co/trade-api/v2 (demo-api.kalshi.co also supported).
  • Recommended Demo WebSocket: wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 (demo-api.kalshi.co also supported).
  • Orderbook Reciprocal Pricing: orderbook_fp returns bids only (yes_dollars, no_dollars); YES Ask = $1.00 − NO Bid.
  • Candlesticks Constraint: REST candlesticks support 1m, 60m, and 1440m intervals only; Seconds charts require real tick aggregation (flagged in IRREG-04).

Trading, Lifecycle & Verification Discipline

  • Strict 5-Topic Scope: Gas Prices, Elections, Culture, Crypto, and Golf only — isolated into dedicated subpages.
  • Lifecycle Resolution: Catalog status is static; settlement controls in Portfolio simulate YES/NO outcomes.
  • Automated Strategy Testing: Swing Mean-Reversion, Momentum Breakout, illustrative model filter, Spread Capture, plus custom category-based strategies on Portfolio & Strategies.
  • Zero Hallucination Policy: Unverified values are left blank and published transparently on Flagged for Review.
