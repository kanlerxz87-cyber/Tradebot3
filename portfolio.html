Automated strategy lab

Backtests run automatically on official 1-minute Kalshi candles.
Read this first. The snapshot holds roughly two hours of 1-minute candles per tracked market, so these are small-sample simulations, not evidence of a durable edge. Results are shown gross of fees.

Live auto-trade (paper)

When a ≥ $0.10 swing is detected by the live poll, the selected strategy can immediately open a 10-contract paper position. It is capped at one open position per market and uses the same transparent rules as the backtest.

Build a strategy from a category

Once the trade log has data, sort the category table above by P&L, then enable auto-trade with the matching category. Because every fill is tagged with its category, you can compare the same market across momentum, fade and model-filtered entries.

Kalshi demo account (optional, read-only)

keys stay in browser memory

Create an API key in the Kalshi demo environment (demo keys do not work in production and vice versa). Paste the Key ID and the private key PEM (RSA or Ed25519) below. The browser signs GET /trade-api/v2/portfolio/balance with RSA-PSS (SHA-256, salt 32) exactly as Kalshi's API-key guide describes, and sends it to https://external-api.demo.kalshi.co/trade-api/v2. The private key is never stored, logged or committed.

Two limits are worth knowing before you try: browsers cannot use Ed25519 keys through Web Crypto (RSA only), and Kalshi's demo API may not send CORS headers, in which case the request is blocked by the browser. If that happens the paper account still works normally — the message below will say so.
